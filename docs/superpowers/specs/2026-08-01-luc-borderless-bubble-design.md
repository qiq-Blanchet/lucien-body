# Luc 无边框气泡设计

## 目标

移除气泡下方三角箭头与所有橙色/粉色边框，并取消气泡文字加粗，让气泡仅保留圆角背景、正常字重文字和现有显隐动画。

## 设计决定

- 删除 `.bubble::after` 伪元素，避免残留透明三角占位或样式。
- 删除 `.bubble` 的基础边框。
- 删除 `shout` 与 `love` 变体的边框覆盖；各变体仅保留背景、字号和文字颜色差异。
- 将气泡基础字重从 600 改为正常字重 400，所有变体继承该字重。
- 保持气泡层 240x160dp 的底部居中布局、5 秒动画、透明页面和 `pointer-events: none` 不变。
- 不修改 SVG、HTML、Kotlin 或悬浮窗口逻辑。

## 验收标准

在真实浏览器渲染中，normal、whisper、shout、love 气泡四边边框宽度均为 0，伪元素不再生成，计算字重均为 400；气泡仍贴在 240x160 视口底部并水平居中。
